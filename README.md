# 🎰 GameZone Retro

## 📌 Sobre o projeto

O **GameZone Retro** é uma página HTML criada para representar uma loja de jogos clássicos. O objetivo do projeto é praticar conceitos básicos de **HTML**, como títulos, parágrafos, links, imagens, listas e tabelas.

## 🎮 Conteúdo da página

A página apresenta:

* Nome da loja **GameZone Retro**;
* Uma breve descrição da loja;
* Links para visualizar produtos e acessar uma loja externa;
* Imagem relacionada ao tema de games retrô;
* Lista de consoles dispo
