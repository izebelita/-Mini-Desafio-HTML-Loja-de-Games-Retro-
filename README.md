# 🎰 GameZone Retro

## 📌 Sobre o projeto

O **GameZone Retro** é uma página HTML criada para representar uma loja de jogos clássicos. O objetivo do projeto é praticar conceitos básicos de **HTML**, como títulos, parágrafos, links, imagens, listas e tabelas.

## 🎮 Conteúdo da página

A página apresenta:

* Nome da loja **GameZone Retro**;
* Uma breve descrição da loja;
* Links para visualizar produtos e acessar uma loja externa;
* Imagem relacionada ao tema de games retrô;
* Lista de consoles disponíveis;
* Tabela com jogos, consoles e preços.

## 🕹️ Consoles apresentados

* Nintendo (NES)
* Super Nintendo (SNES)
* Sega Genesis
* Atari 2600

| ---------------- | ------- | --------: |

## 🛠️ Tecnologias utilizadas

* **HTML5**
* Estilização básica utilizando `style` diretamente nas tags HTML.

## 🎯 Objetivo

O projeto foi desenvolvido como uma atividade prática para demonstrar o uso dos principais elementos do HTML na criação de uma página simples de uma loja de games retrô.
